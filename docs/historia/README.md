# A história do IbiFX, contada pelos branches

Cada capítulo conta a ideia por trás de uma área do projeto, as decisões e
as dificuldades — o que deu errado, como foi medido e o que mudou por causa
disso. Os commits de cada branch contam a mesma história em pedaços
menores (`git log --format=%B`).

Os branches são empilhados, cada um sai do anterior:

    main -> pedais -> amps -> ir -> motor -> ui

1. [Pedais](pedais.md) — branch `pedais`
2. [Amps](amps.md) — branch `amps`
3. [IR (gabinetes)](ir.md) — branch `ir`
4. [Motor](motor.md) — branch `motor`
5. [UI](ui.md) — branch `ui`
